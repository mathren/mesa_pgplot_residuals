** Kippenhahn style maximum residual across equations

#+DOWNLOADED: screenshot @ 2026-05-19 17:56:12
[[file:.org_notes_figures/2026-05-19_17-56-12_screenshot.png]]


Kippenhahn-style diagram (with mass on the y-axis and model number on
the x-axis) colored by

#+BEGIN_SRC fortran
   safe_log10(maxval(abs(s%equ(1:neq, k))))
#+END_SRC

which is the logarithm of the absolute value of the biggest residual
at cell =k= for the *accepted* iteration of MESA's Newton-Raphson solver.

The y-axis can be Lagrangian mass coordinate, log(R/R_{\odot}), or log(\tau),
chose by setting in the =controls= namelist
#+BEGIN_SRC fortran
x_integer_ctrl(1) = 1 ! 1=mass, 2=radius, 3=tau
#+END_SRC

Note that the y-axis is interpolated on a linear grid for
visualization purposes.

Couple with a =pgplot= with mass as a function of =zone_number= to narrow
the problematic zone.

** How to use

1. paste the following block into =run_star_extras.f90= *before* the =contains=:
#+BEGIN_SRC fortran
  ! for Kippenhahn style local value of  max across equations of residual
  integer, parameter :: NR_MAX_MODELS = 2000
  integer, allocatable, save :: nr_zone_buf(:)
  integer, allocatable, save :: nr_model_buf(:)
  integer,              save :: nr_n_stored = 0, nr_n_cells = 0
  real, allocatable, save :: nr_resid_buf(:,:), tmp_resid_buf(:,:)
  real, allocatable, save :: nr_mass_buf(:,:), tmp_mass_buf(:,:)
  real,              save :: nr_resid_min = -101.0, nr_resid_max = -101.0  ! auto-scale
  ! to select y-axis
  integer, parameter :: NR_COORD_MASS   = 1
  integer, parameter :: NR_COORD_LOGR   = 2
  integer, parameter :: NR_COORD_TAU    = 3

  ! for max residual across all cells for each equation
  integer, parameter :: max_resid_hist = 2000
  integer            :: n_resid_hist   = 0
  integer            :: resid_hist_nvar = 0
  integer,       allocatable :: resid_hist_model(:)        ! (max_resid_hist)
  real,          allocatable :: resid_hist_vals(:,:)       ! (nvar, max_resid_hist)
  character(len=32), allocatable :: resid_equ_names(:)
#+END_SRC
to create some global variables accessible for these routines.

2. after =contains= in =run_star_extras.f90=, add:
#+BEGIN_SRC fortran
   include 'pgstar_residuals.inc'
#+END_SRC
3. In extras_controls:
   a. to get a "Kippenhahn-style" map of mass coordinate vs. model number
   colored by the maximum residual (across all equations) for each location:
#+BEGIN_SRC fortran
        s% other_pgstar_plots_info => nr_resid_kipp_plots_info
#+END_SRC
    b. to get a plot as a function of model number of the maximum
       (across mesh points) residual for each structure equation
#+BEGIN_SRC fortran
    s% other_pgstar_plots_info => equ_resid_hist
#+END_SRC

See also comment at the top of the file =pgstar_residuals.inc=.

** *Warnings*
These plots will be saved in a subfolder =png= of your work directory,
this is hardcoded.
